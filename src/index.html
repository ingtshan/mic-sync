⚠️ 未检测到 BlackHole 虚拟声卡

客户端需要 BlackHole 才能把远端麦克风虚拟成本机麦克风。请前往官网下载图形安装器(推荐,免费,需填邮箱获取下载链接),下载后双击 .pkg 按提示完成安装:

备选方式 · Homebrew(注意:若跳过密码授权会静默失败,装完务必核对):

brew install blackhole-2ch

⚠️ 安装完成后需要重启电脑(或在终端执行 sudo killall coreaudiod 重启音频服务),BlackHole 才会生效。生效后本提示会自动消失,之后在其他软件里选择「BlackHole 2ch」作为麦克风即可。

⚠️ 未检测到 VB-Cable 虚拟声卡

客户端需要 VB-Cable 才能把远端麦克风虚拟成本机麦克风。前往官网下载 VBCABLE_Driver_Pack(免费),解压后右键「以管理员身份运行」VBCABLE_Setup_x64.exe 完成安装:

⚠️ 安装完成后需要重启电脑,VB-Cable 才会生效。生效后本提示会自动消失,之后「输出到」选择「CABLE Input」,会议软件里选择「CABLE Output」作为麦克风即可。

「自动跟随」:开启时先向对方请求一次授权(对方同意前不会开麦);之后检测到本机有应用把 BlackHole 当麦克风采集(如进入会议)时,自动向服务端请求麦克风,应用停止采集约 2 秒后自动释放、远端关麦——全程无需手动点击(需 macOS 14+)。「手动使用」则立即请求、手动停止。两种模式下,另一台设备发起请求都会自动接管,本机随之停止——人在哪台设备,麦克风就跟到哪台。
