客户端需要 BlackHole 才能把远端麦克风虚拟成本机麦克风。请前往官网下载图形安装器(推荐,免费,需填邮箱获取下载链接),下载后双击 .pkg 按提示完成安装:

备选方式 · Homebrew(注意:若跳过密码授权会静默失败,装完务必核对):

brew install blackhole-2ch

⚠️ 安装完成后需要重启电脑(或在终端执行 sudo killall coreaudiod 重启音频服务),BlackHole 才会生效。生效后本提示会自动消失,之后在其他软件里选择「BlackHole 2ch」作为麦克风即可。

开始监听后不会持续占用带宽:只有服务端麦克风有人说话时才自动拉取音频,说完自动回到待机。
